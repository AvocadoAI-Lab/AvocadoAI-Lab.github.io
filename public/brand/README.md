# AvocadoAI brand assets

`avocadoai-logo.png` is the transparent 1024 × 681 PNG supplied and approved for portal use by the repository owner on 2026-08-31. The source file is preserved without raster modification; `src/components/logo.tsx` crops transparent padding at render time and provides a light backing surface in dark contexts.

The image SHA-256 is `38464908659cda329b07392b5f7a35ce712b853461c894374c1b28dc47b73823`.

Clear-space rules, alternate color variants, social-preview assets, and any associated font licensing remain to be documented. Do not commit licensed font files.

`src/app/icon.png` is the 512 × 512 transparent browser icon derived from the approved logo. It contains only the centered avocado/gecko emblem without the wordmark and replaces the temporary `AI` SVG favicon.
